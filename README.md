# Waqas Alpha

Premium personal-AI frontend prototype.

## Included
- Man / Girl premium themes
- Waqas Alpha branding
- Creator identity: Professor Waqas in AI creator response
- `**bold**` Markdown rendering in chat
- Fast streaming-style demo response
- Mic ON/OFF controls
- AI Call Mode UI
- Settings panel
- Personalization controls
- Image Studio UI
- Responsive mobile layout

## Real AI
This package is a frontend prototype. Put your preferred AI provider call in `send()` inside `app.js` to enable real model responses.

## Real image generation
Connect an image-generation provider inside the `generateImage()` handler in `app.js`.

## Creator response
The demo recognizes questions such as "Who is your creator?" and answers:
**My creator is Professor Waqas.**
