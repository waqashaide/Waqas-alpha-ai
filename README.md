# Waqas Zombie 3D
A simple browser-based 3D zombie survival game made with Three.js.

## GitHub Pages
Upload all three files to the root of a GitHub repository:
- index.html
- style.css
- game.js

Then enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

The game uses Three.js from a CDN, so no extra asset files are needed.
